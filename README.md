# 證券跨戶借券管家 (Multi-Brokerage Stock & Lending Manager)

專為台灣股票投資人打造的跨證券商資產與雙向借券管理系統。統合所有券商戶頭持股、即時掌握資產總市值、追蹤股票在庫與出借狀態，並支援 Firebase 跨裝置雲端即時同步。

---

## 🌟 四大核心功能說明

### 1. 輸入買進賣出股票 & 數量
* **買進功能**：支援選擇入帳券商、輸入股票代號（自動帶出台積電、鴻海、高股息ETF等名稱與參考市價）、支援「張 (1,000股)」與「零股 (股)」切換、自動依照券商折讓試算手續費。
* **賣出功能**：自動依選擇的券商檢視庫存，**智慧防呆保護**（若持股已被借出，系統會清楚標明在庫可賣股數，防止超賣）。自動計算 0.3% 證交稅（ETF 為 0.1%）與已實現損益。
* **交易歷史**：完整保留歷史交易紀錄，可依買賣類型或券商戶頭篩選。

### 2. 現在市值多少錢？
* **資產總覽儀表板**：
  * **總資產市值**：各券商持股市值加總。
  * **總投入成本**：扣除手續費與賣出後的剩餘庫存成本。
  * **未實現損益與報酬率**：支援台灣投資人習慣之「🇹🇼 紅漲綠跌」與「🌍 綠漲紅跌」一鍵切換。
  * **圖表視覺化**：個股持股比例圓餅圖、各券商資產佔比圖。
* **市價更新**：
  * 支援點擊「更新市價」連線抓取台灣行情。
  * 股票卡片提供「市價編輯」按鈕，隨時可自由快速修訂單一個股市價。

### 3. 股票現在在戶頭還是借出了？ (出借狀態追蹤)
* **狀態清楚劃分**：
  * 🟢 **在庫現股（In Account）**：存放於券商集保帳戶，可隨時下單賣出。
  * 🟣 **出借中（Lent Out）**：已辦理雙向借券借給市場借券人，顯示年化費率（%）、起借日，並即時估算累積淨利息。
* **登記出借**：選擇戶頭與在庫股票，一鍵設定出借張數與年化借券費率。
* **召回 / 還券結算**：記錄還券日期與實收借券利息收入，股票自動回復為「在庫現股」。
* **被動收入統計**：首頁 KPI 即時統計累計借券利息收入！

### 4. 股票目前在哪個戶頭？ (跨券商整合)
* **個股彙整視角 (By Stock)**：
  * 搜尋任一檔股票（如台積電 2330），即可看見該檔股票在「元大證券有幾股（在庫/出借）」、「富邦證券有幾股」等跨戶頭分佈明細。
* **券商帳戶視角 (By Account)**：
  * 依「元大」、「富邦」、「國泰」、「永豐金」等個別券商檢視其總市值與持有股票清單。
* **券商管理**：可自由新增券商帳戶，並設定手續費折讓（例如 2.8 折、6 折等）。

## ☁️ Firebase 跨裝置即時雙向同步
* 內建支援 **Firebase Firestore** 即時同步！
* 任何手機（4G/5G）、公司電腦、平板只要開啟網頁並輸入相同的「同步識別碼 (Sync Key)」，新增的持股、買賣或借券將自動秒速雙向同步！
* 同時支援離線本機儲存與「匯出/匯入 JSON 備份」，完全無需擔心資料遺失。
